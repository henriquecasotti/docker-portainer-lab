# Portainer CE e Docker

Projeto desenvolvido para aprendizado de gerenciamento de containers Docker utilizando Portainer CE em ambiente Linux.

## Objetivos

- Aprender gerenciamento de containers
- Utilizar Docker Compose
- Trabalhar com Stacks
- Centralizar o gerenciamento de serviços Docker
- Documentar a infraestrutura de forma organizada

## Tecnologias

- Linux Mint
- Docker
- Portainer CE
- Docker Compose

## Atividades Realizadas

- Instalação do Portainer CE
- Configuração do ambiente Docker
- Resolução de problemas relacionados ao Setup Token
- Criação da primeira Stack utilizando Docker Compose
- Implantação de container Nginx via Portainer

## Próximos Passos

- Migrar o Homarr para Docker Compose
- Gerenciar serviços através de Stacks
- Implementar Nginx Proxy Manager
- Estudar HTTPS e Reverse Proxy
